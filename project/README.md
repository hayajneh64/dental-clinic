# عيادة د. عماد ظهيرات لطب الأسنان

موقع إلكتروني حديث لعيادة أسنان يحتوي على:
- صفحة رئيسية احترافية
- حجز موعد
- حالات قبل وبعد
- تواصل مباشر عبر واتساب

## 🚀 كيف تستخدم المشروع

### 1. تشغيل محليًا
```bash
npm install
npm run dev
```

### 2. نشر على Vercel أو Netlify
- اربط هذا المستودع على GitHub
- أنشئ مشروع على [vercel.com](https://vercel.com) أو [netlify.com](https://netlify.com)
- سيقوم بنشره تلقائيًا بعد كل تحديث

### 3. بنية الصفحات

| الصفحة | الملف |
|--------|--------|
| الصفحة الرئيسية | `/src/pages/Home.tsx` |
| الحجز | `/src/pages/Appointment.tsx` |
| قبل وبعد | `/src/pages/BeforeAfter.tsx` |
| التواصل | `/src/pages/Contact.tsx` |

---

## 🛠 التقنيات المستخدمة
- React + TypeScript
- TailwindCSS
- Vite
